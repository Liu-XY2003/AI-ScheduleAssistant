### ⚠️ 关于签名

这个 APK 是 **debug 构建**，用调试密钥签名，且 `android:debuggable=true`。
首次发布先用它把流程跑通，**不建议长期使用**：

- 体积更大、启动略慢（没有 R8 压缩）
- 后续如果换成正式密钥签名，**必须先卸载旧版**才能装新版（Android 不允许换签名覆盖安装）
- 正式签名需要你保管一个 keystore，丢了就无法给已安装的用户推送更新

准备正式发版时告诉我，我会生成 keystore、配好 `signingConfig` 并出正式包。

## 安装

```bash
adb install -r AI-ScheduleAssistant-v0.1.0-debug.apk
```

或者把 APK 传到手机上点击安装（需要允许「安装未知来源应用」）。

## 配置

1. 电脑上先启动后端（见后端仓库的快速开始）
2. App 里进「设置」，填**你自己电脑**的地址：
   - 同一个 Tailscale 网络 → `http://100.x.y.z:8800`（推荐，端到端加密）
   - 同一个 WiFi → `http://192.168.x.y:8800`
   - USB 转发 → `http://127.0.0.1:8800`（先跑 `adb reverse tcp:8800 tcp:8800`）
3. 后端如果设了 `SCHED_TOKEN`，把同一个值填进「访问令牌」
4. 顶栏出现 **● 已连接** 就好了

## 这一版有什么

- **添加日程**：中文一句话 → 结构化指令 → 写进日历
- **结果卡片**：把整条链路摊开（模型原始输出、契约校验、每步耗时），小模型偶尔解析有歧义时能看清到底发生了什么
- **日历**：月视图按类型着色，点日期看详情，下方备忘区
- **两套主题**：纸感 / 夜航，设置页有实时预览卡片，可选跟随系统；显式选择会覆盖系统深浅色
- **访问令牌**：后端设了令牌时能正确区分「未连接」和「需要访问令牌」

配色与网页版共用同一份 token（`theme/tokens.json`），两边不会走散。

## 已知限制

| 限制 | 说明 |
|---|---|
| 只能添加 | 后端的 `action` 目前只有 `add`；改 / 删要在日历里手点 |
| 电脑必须开机 | 架构决定的 |
| 无提醒推送 | 日程存在电脑端，手机不会主动弹通知 |
| 日历不显示跨天事件 | 只按开始日期归到某一天 |
| 明文 HTTP | Tailscale 本身端到端加密，因此放开了 `usesCleartextTraffic` |
